## 为什么"美国公司"和"香港机房"并不矛盾

因为这家公司卖的不是"美国服务器"，是"从中国大陆访问快的亚太服务器"。

官方文档列出的接入点是香港（HKG）、日本（JPN，东京）、新加坡（SIN）。产品总览页给三地的定位很直白：香港邻近中国大陆、延迟最低、产品线最全；东京是亚太核心节点；新加坡是东南亚枢纽。官网首页的卖点只有一句——中国大陆方向 RTT 低于 50ms。官方文档给的节点延迟指标是东京 < 50ms、新加坡 < 70ms。

线路方案是三网直连：电信 CN2、联通 AS9929、移动 CMI，配合按源 IP 自动选择最优回程的智能路由、多上游冗余和自动故障切换。第三方拆得更细一些，去程电信走 163/CN2、联通 4837、移动 CMI，回程电信 CN2、联通 9929、移动 CMIN2。

所以注册地、机房位置、目标用户这三件事本来就分属不同层面。一家在美国注册的公司，把机器放在香港卖給大陆用户，逻辑上完全通顺——它卖的就是这段跨境链路的品质。
